# Better Endfield Next Android

本目录提供 Android ARM64 的 LSPosed 模块、设置应用和游戏内悬浮面板。当前源码跟进上游 `4.1.8`，应用包名为 `dev.betterendfield.next`；本地派生分支继续保留内置第一人称、陀螺仪、第三方模块入口和 Compose 设置界面。当前产品边界见[产品边界](../docs/PRODUCT_BOUNDARY.md)。

本次上游合并使用 Next 身份。旧包名 `dev.betterendfield.android` 与 Next 是两个独立应用，安装不会迁移旧应用设置或框架作用域；请在框架中启用 Next 并重新选择实际游戏作用域。不要同时对同一游戏启用两个模块。可先保留旧应用及数据，完成新包验证后再决定旧应用处理方式。

本地 Debug 与 Release 继续使用各自的固定签名配置；并未采用上游维护者的 Release 私钥。相同包名的更新仍需使用相同签名。此分支源码、宿主检查和 APK 构建结果不能替代设备运行与用户视觉验收。

## 使用要求

- Android 10 及以上、ARM64，以及支持 libxposed API 102 的框架环境。
- 作用域需包含实际安装的游戏包名。预选包名包括 `com.hypergryph.endfield` 和 `com.gryphline.endfield.gp`；其他渠道请按实际包名设置。
- 第一人称内置头饰目录使用完整 `v3` 清单：游戏 versionCode `61`、共 `898` 份资源。渠道、客户端版本和逐角色效果仍需分别验证。

## 安装与配置

1. 安装本分支构建的 APK，在框架中启用 Next 并设置游戏作用域。
2. 打开应用配置所需模块，再完整重启游戏。
3. 进入游戏后用悬浮面板操作自由镜头、时间暂停、第一人称和 MMD 等功能。
4. 设置与运行日志可以从应用导出。排查时请同时保留失败时间、应用版本、游戏版本和相应日志。

PC 界面使用游戏自身的输入模式切换，默认关闭；部分触控控件会随游戏布局切换而隐藏。关闭悬浮面板与折叠面板的行为不同：折叠保留拖动手柄。

第一人称与陀螺仪继续由本地相机模块处理。头饰资源只决定已支持模型的隐藏与替换数据；完整清单校验不代表每个角色都已通过实机视觉验收。

## 模型与 MMD

BEM 管理器接受 BEM 文件、ZIP 单模型包和包含多个 BEM 的 ZIP 合集。导入合集后先选择要安装的包。应用按角色或武器目标展示，平台兼容、资源冲突和选项合法性由模型 owner 校验。

包选择保存使用安装索引修订号：列表已被其他入口更新时，旧草稿会被拒绝，需刷新后重新操作。游戏内局部编辑与设置应用保存共用同一校验和提交 owner。

原样导入保留包内容。贴图转换、法线修复和实验性模型热切换按对应操作执行。加载优化、关闭模型校验、热切换统一属于模型实验设置；不能用关闭校验掩盖错误平台或不完整输入。

MMD 支持本地动作、表情、镜头和音频，以及作品目录。文件通过框架共享文件空间发布，再复制到游戏自己的目录；应用私有路径不能直接当作游戏可读路径。导入失败、短读或框架断连不能记录为已安装。

第三方模块入口保留 ARM64 原生模块和可选离线网页界面。二进制更新、卸载和加载顺序变化需要重启游戏。模块作者仍负责自己的游戏接口、线程与状态恢复。

工具页可打开 Compose 会客室媒体屏设置，选择图片、轮播图片或 MP4 后保存，并冷重启游戏使其生效。媒体文件仍由原有框架共享空间发布，配置沿用原有字段和索引。工具页另有上游创意工坊入口；关于页提供语言切换、软件更新、资源包导入与更新、项目和社区链接。启动时自动检查可在关于页关闭。旧 View 版 MMD 作品页已由当前 Compose MMD 页及作品导入链取代。

## 本地构建

需要 JDK 21、Android SDK platform 37、NDK `27.2.12479018`、CMake、Dobby 及已安装的 Gradle 依赖。工具路径与构建目录通过仓库工作区配置解析；构建产物、缓存和临时文件应放在配置的外部目录。

头饰资源必须提供完整且已校验的 `898/v61` 目录。示例从仓库根目录执行：

```powershell
$catalog = 'D:/codexdata/bem-headwear-v61-20261017/catalog'
.\android\gradlew.bat -p android :app:assembleDebug "-PheadwearCatalogDir=$catalog" --offline
```

构建会验证每份资源的哈希及清单覆盖范围；缺少资源会直接失败。CI 需显式提供当前头饰归档来源，不能回退到旧 `834` 份资源包。本机准备的完整归档可用 `tools/Camera/fetch_android_headwear_catalog.py --archive <归档路径>` 导入；在线来源使用该工具的显式参数或 `HEADWEAR_CATALOG_URL`。

Debug 签名读取 `android/keystore/debug.properties`，Release 签名读取 `android/keystore/release.properties`。Release 私钥不提交仓库；不能用临时生成的密钥替代现有发行身份。生成的源码、资源包和 APK 均通过构建任务产出。

## 验证入口

宿主门禁从仓库根目录执行：

```powershell
python -B tools/AndroidPort/run_host_gate.py --java-home '<JDK 21 目录>' --work-dir 'D:/codexdata/bem-host-check'
```
